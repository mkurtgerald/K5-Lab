# Publication boundary

Public: replaceable donor adapters, generic record contracts, synthetic examples,
validation, generic metrics, tests, and narrowly scoped infrastructure tasks.

Not public: deployment vocabularies, proprietary graph extensions, feature
engineering, training objectives/rewards, response policies, tuned parameters,
learned weights, embeddings, real metadata, media, protected adapters, customer
information, commercial plans, or meaningful benchmarks of protected systems.

Do not clone a private repository in this workspace. Never rely on renaming,
encoding, branches, ignored folders, workflow secrets, or later deletion to
keep uploaded material private. Public issues and build logs are public too.
Keep all protected work in separate access-controlled repositories and build
infrastructure. Only immutable, reviewed generic packages flow across that
boundary. Protected callers adapt their own contract without importing their
source into this repository.

All demonstrations are generic synthetic scaffolding. They do not implement
or document any downstream product's differentiated logic.
