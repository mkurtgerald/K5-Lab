# Security

Do not put credentials, protected material, real identifiers, private systems,
or exploitable vulnerability detail in public issues or logs. Use a separately
authorized private reporting channel; none is configured by this scaffold.

The library has no external action executor and no network client. The public
scanner is a lightweight pre-publication check, not a DLP system or guarantee.
Repository administrators must independently configure required checks, protected
branches, secret scanning/push protection where available, and contributor access.
Those remote settings are not enabled merely by including this file.
